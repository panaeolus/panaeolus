Actual API:
  (require '[panaeolus.instrument :as p]
           '[panaeolus.sampler :as sampler]
           '[panaeolus.fx :refer [flanger bbcut]])
  (def kick (p/with-defaults
    (sampler/load "samples/kick.wav" :id :kick :normalize false) :cross 0))
  (kick) ; one shot, default parameters and file duration
  (kick :every [1] :amp 0.8 :offset 0)
  (bass :every [0.75 0.25 0.5 0.5]
    :dur 0.19 :rate [1 2 1 1.4983] :amp 0.5)
  (hat :every [0.25] :amp [0.1 0.2 0.1 0.3]
    :fx (bbcut :bpm 128 :subdiv 8 :repeats 2))
  (p/stop! bass)
  (p/stop-all!)

Durations in :every and :offset are beats; :dur and :cross are seconds. :rate changes both speed and pitch. :start and :end are fractions of the sample. All parameter vectors cycle independently. Repeating an instrument call replaces that instrument's named loop. Omitting :fx removes its effects from new notes. Each call starts from defaults; omitted parameters do not retain the last call's values. Valid modes at load time are :forward, :reverse, :pingpong. There are no negative-duration rests. Use separate loops, amplitude zero, or stop! for gaps. For one-shots, use :cross 0 and keep :dur within the sample's duration at the chosen playback rate. Resolve sample paths relative to the demo folder, and create the same samples/ paths in the browser engine. Do not invent filters, effects, sequencing functions, or keyword arguments.
